
# Telegram-бот с RAG по документам

Telegram-бот, который отвечает на вопросы по документам, присланным пользователем. Документы режутся на фрагменты(чанки), превращаются в векторы и ищутся по смыслу, а ответ генерирует языковая модель.

## Возможности

- загрузка файлов `.docx`, `.txt`, `.md` прямо в чат;
- поиск по смыслу (embeddings `multilingual-e5-large`) в ChromaDB;
- ответы с указанием источника;
- несколько диалогов на пользователя с историей в SQLite;
- кнопки управления диалогами и файлами.

## Схема работы

документ → фрагменты → embeddings → ChromaDB → поиск по вопросу → LLM → ответ

## Установка

```
pip install -r requirements.txt
```

## Переменные окружения

Задаются в конфигурации запуска, в код не вписываются:

| Переменная | Что это |
|---|---|
| `telegram_token` | токен бота от @BotFather |
| `LLM_BASE_URL` | адрес OpenAI-совместимого API |
| `LLM_API_KEY` | ключ API |
| `LLM_MODEL` | название модели |

## Запуск

```
python menstral.py
```

Бот запускается, после этого напишите ему в Telegram.

## Структура

- `menstral.py` — обработчики Telegram
- `rag.py` — документы, фрагменты, embeddings, поиск
- `db.py` — пользователи, диалоги, история (SQLite)
